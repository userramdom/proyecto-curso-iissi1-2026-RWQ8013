# Instrucciones para configurar el repositorio del grupo

Todo el proceso se realiza en la plataforma **GitHub**. Asegúrate de tener una cuenta creada e iniciada la sesión antes de empezar.

> **Importante:** solo **un miembro del grupo** debe crear el repositorio a partir de la plantilla (pasos 1 y 2). El resto de compañeros se incorporan como colaboradores (paso 3).

---

## 1. Crear tu repositorio a partir de la plantilla

1. Abre la página del repositorio plantilla en GitHub. https://github.com/IISSI1-IS-2026/plantilla-proyecto-curso
2. Pulsa el botón verde **`Use this template`** (arriba a la derecha).
3. Selecciona **`Create a new repository`**.
4. Rellena el formulario:
   - **Owner:** selecciona tu **cuenta personal** de GitHub.
   - **Repository name:** escribe un nombre para el repositorio segun este patrón: `proyecto-curso-iissi1-2026-{UVUS_DEL_OWNER}`.
    
        Por ejemplo, si el repositorio lo creó el usuario con uvus `XFD43` el nombre del repositorio sería `proyecto-curso-iissi1-2026-XFD43`.
   - **Visibility:** comprueba que está seleccionado "Public".
5. Pulsa **`Create repository`**.

Ya tienes una copia del repositorio en tu espacio personal de GitHub.

---

## 2. Añadir a tus compañeros como colaboradores

Esto permite que tus compañeros puedan leer y escribir en el repositorio (hacer `push`, crear ramas, abrir *pull requests*, etc.).

1. Entra en la página de tu repositorio en GitHub.
2. Pulsa en la pestaña **`Settings`** (⚙️), en la barra superior del repositorio.
   - Si no ves `Settings`, despliega el menú `...` de la barra de pestañas.
3. En el menú lateral izquierdo, dentro de la sección **Access**, pulsa en **`Collaborators`**.
4. Es posible que GitHub te pida confirmar tu identidad (contraseña o autenticación en dos pasos). Confírmala.
5. Pulsa el botón **`Add people`**.
6. Escribe el **nombre de usuario de GitHub**, el **nombre completo** o el **correo electrónico** de tu compañero y selecciónalo en la lista de sugerencias.
7. Pulsa **`Add [usuario] to this repository`**.
8. Repite los pasos 5–7 para cada miembro del grupo.

Los colaboradores de un repositorio de una cuenta personal reciben automáticamente **permisos de escritura**, suficientes para trabajar en el repositorio.

### Aceptar la invitación (lo hace cada compañero invitado)

- Cada compañero recibirá una invitación por **correo electrónico** y en las **notificaciones de GitHub**.
- Debe abrirla y pulsar **`Accept invitation`**.
- También puede aceptarla entrando directamente en: `https://github.com/NOMBRE_USUARIO_GITHUB/NOMBRE_DEL_REPOSITORIO/invitations`
- ⚠️ Las invitaciones **caducan a los 7 días**. Si caduca, el propietario del repositorio debe volver a enviarla.

Mientras la invitación no se acepte, el compañero aparecerá como **Pending invite** en la lista de colaboradores.

### 📝 Datos que se piden en el formulario

En el formulario se te pedirá la siguiente información:

1. **URL del repositorio creado:** es la dirección de la página principal del repositorio en GitHub. Puedes copiarla directamente de la barra de direcciones del navegador cuando estés en el repositorio. Tendrá este formato:

    ```
    https://github.com/NOMBRE_USUARIO_GITHUB/NOMBRE_DEL_REPOSITORIO
    ```

   Por ejemplo, si el repositorio lo creó el usuario github `manologarcia` con uvus `XFD43`, la URL sería:

    ```
    https://github.com/manologarcia/proyecto-curso-iissi1-2026-XFD43
    ```

    > Todos los miembros del grupo deben indicar **la misma URL**: la del repositorio creado por el compañero que usó la plantilla, no la de la plantilla original.

2. **Grupo de laboratorio** al que perteneces, desde L1 a L8.
